# This is my final promotional Task for Kodecamp 6

## This is an E-commerce Website with the following pages

- Landing Page
- Individual Product Page
- Add-to-Cart Page
- Checkout Page

### Flow

#### Landing Page First

Inserted font awesome into the project
First i had to insert the link to the head of my html doc

```html
<link
  rel="stylesheet"
  href="https://cdnjs.cloudflare.com/ajax/libs/font-awesome/7.3.0/css/all.min.css"
/>
```

Then i added the class of the of the icons to the body of the code

```html
<i class="fa-solid fa-cart-shopping"></i>
```
